# RAG Frontend 视觉重构设计稿

日期：2026-10-26
状态：待评审
方案：B（设计系统 + 外壳重构，保留现有技术栈）

> 2026-10-26 视觉方向更新：整体改为深空蓝暗色主题，去掉所有纯白表面；问答页使用纯 CSS 星空背景 + 居中毛玻璃输入框。具体 token 和实现以 `src/assets/global.css`、`src/components/Starfield.vue`、`src/components/ChatComposer.vue` 为准。

## 1. 背景与目标

现有前端是 Vue 3 + Element Plus 的樱花粉液态玻璃风格，视觉上偏装饰化、emoji 图标与页面内联样式不统一，长文阅读和表格密集页面的可读性一般。

本次目标：

- 去掉粉色和液态玻璃，建立一套克制、现代、生产级的设计语言
- 统一颜色、字体、间距、圆角、图标和动效
- 重构侧栏、登录页、聊天页和全部管理页面的视觉与布局
- 补齐响应式、加载、错误和空状态
- 保持现有功能和后端接口不变，只修与 UI 真实性直接相关的小问题

## 2. 非目标

- 不迁移到 React / shadcn / Radix / Tailwind
- 不引入 Tailwind、TanStack Query、Zustand、dnd-kit、react-resizable-panels
- 不做明暗主题切换
- 不重写后端接口
- 不做与本次视觉重构无关的业务功能扩展

## 3. 技术约束

保留：

- Vue 3.5 + Vite 5
- Element Plus 2.13（表格、表单、弹窗、上传、分页等全部复用）
- Pinia、Vue Router、axios、ECharts、marked、ali-oss

新增依赖仅一个：

- `lucide-vue-next`：统一图标，替换 emoji 和无效的字符串 icon

侧栏专用：

- 默认文字 `hsl(220 14% 78%)` / `#BFC4CF`
- 辅助文字 `hsl(220 10% 55%)` / `#818898`
- 激活文字 `#FFFFFF`

- 激活左侧 2px 科技蓝指示条

禁止：

- 粉色系
- 大面积玻璃拟态 `backdrop-filter`
- 大面积高饱和渐变
- 纯黑背景配纯白文字的高对比组合

### 4.2 字体

- 拉丁：`Manrope`
- 中文：`Noto Sans SC`
- 等宽：`JetBrains Mono`
- 回退：`-apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`

字号：

| 层级 | 字号 | 字重 |
| --- | --- | --- |
| 页面标题 | 22–24px | 600 |
| 卡片/区块标题 | 15–16px | 600 |
| 正文 | 13–14px | 400/500 |
| 辅助文字 | 11–12px | 400/500 |
| 数字/Key/代码 | 12–14px | 400/500，等宽 |

辅助标签使用大写/字距 `0.06em–0.08em` 的英文小标签。

### 4.3 间距、圆角、阴影

- 间距基准 4px，常用 8 / 12 / 16 / 20 / 24 / 32
- 页面内边距：桌面 32px，平板 20px，手机 16px
- 卡片内边距：20–24px
- 圆角：控件 8px，卡片 12px，大面板/弹窗 16px，胶囊 999px
- 阴影只保留两级：
  - `0 1px 2px rgba(16, 24, 40, 0.04)`
  - `0 8px 24px rgba(16, 24, 40, 0.06)`

### 4.4 图标与动效

- 使用 `lucide-vue-next`
- 尺寸 16 / 18 / 20px，线宽 1.75
- 替换所有 emoji：🌸🤖📜📚🚫📊👤 等
- 过渡 150–200ms `ease`
- 页面内容进入：8px 上移 + 淡入
- 卡片悬停：最多 1px 抬升，不做缩放
- 支持 `prefers-reduced-motion: reduce`

## 6. 状态、响应式与无障碍

### 6.1 加载

- 表格、卡片使用 `v-loading`
- 提交按钮使用 `loading`
- 流式回答使用独立 streaming 状态
- 首次加载的统计区可使用 `el-skeleton`

### 6.2 空状态

- 统一 `el-empty` 的视觉：图标、标题、说明、操作按钮
- 每个列表页都提供明确动作，不只显示「暂无数据」

### 6.3 错误状态

- 新增 `src/components/ErrorState.vue`
- 结构：AlertTriangle 图标 + 错误标题 + 后端返回的 `msg` + 重试按钮
- 使用范围：知识库、历史记录、敏感词、敏感词分类、个人中心、API 配置
- 登录页使用表单内错误提示，聊天页使用消息气泡，不套用 ErrorState
- 所有页面移除假数据兜底
- axios 响应拦截器提取后端 `err.response.data.msg`，供页面展示

### 6.4 响应式断点

| 断点 | 行为 |
| --- | --- |
| ≥1280px | 侧栏 248px，页面 padding 32px，内容最大宽度 1280px |
| 1024–1279px | 侧栏 232px，页面 padding 24px |
| <1024px | 侧栏抽屉 + 56px 顶栏，页面 padding 20px |
| <768px | 统计卡 2 列，用户中心单列，表格横向滚动 |
| <480px | 对话框接近全宽，按钮全宽，聊天气泡最大 88% |

### 6.5 无障碍

- 所有可交互元素有 `:focus-visible` 科技蓝 ring
- 图标按钮加 `aria-label`
- 正文对比度达到 WCAG AA
- 动效尊重 `prefers-reduced-motion`

## 7. 与 UI 真实性直接相关的小修复

以下修复不改变后端接口，只避免界面展示错误信息或无效控件：

1. 登录错误读取 `res.msg`
2. 个人中心 / API 配置移除硬编码假数据，改为错误态 + 重试
3. API Key 不再二次截取，直接展示后端脱敏值
4. 移除个人中心「新密码」字段（后端忽略）
5. 移除 API 配置「首选模型」下拉（verify 接口不接收）
6. 敏感词分类页分页拉全量后统计
7. 知识库统计卡拉全量（上限 500）后统计
8. 敏感词删除确认从原生 `confirm()` 改为 `ElMessageBox`
9. 退出登录调用后端 `/user/center/logout`
10. axios 响应拦截器把后端 `msg` 暴露给调用方，页面展示真实错误
